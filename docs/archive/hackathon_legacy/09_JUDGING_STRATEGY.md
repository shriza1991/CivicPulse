# 09 — Judging Strategy

## 20% Problem-Solution Fit
Maximum-score evidence:
- clear planner/policymaker user
- clear fragmented-data decision problem
- direct mapping from problem → capability
- evidence-backed real/realistic data
- complete end-to-end flow.

Avoid:
- describing only citizen reporting
- generic “AI improves governance” claims.

## 25% AI / Technical Execution
Maximum-score evidence:
- Google AI is genuinely central
- structured multimodal/multilingual understanding
- meaningful correlation/reasoning
- deterministic score + AI explanation separation
- robust fallbacks
- explainability
- tests
- cost-aware architecture.

Avoid:
- one generic chatbot prompt
- LLM-only arithmetic
- “AI agent” labels without meaningful roles.

## 20% Cross-Border Applicability
Maximum-score evidence:
- at least 3 demonstrated country configurations
- country-neutral domain model
- localized inputs/data
- shared pipeline
- clear adapter/config architecture.

Avoid:
- “works globally” without demonstration.

## 10% Impact Potential
Maximum-score evidence:
- affected population
- demand volume
- infrastructure gap indicators
- evidence-backed scale framing
- transparent assumptions.

Avoid:
- fabricated monetary savings
- unsupported claims of national impact.

## 20% Deployability & Scalability
Maximum-score evidence:
- deployed public prototype
- containerized architecture
- clean data interfaces
- scalable separation between ingestion, processing and UI
- monitoring/health checks
- reproducible seeded demo
- portable data adapters.

Use Google Cloud where it materially helps and is available; do not make unsupported claims.

## 5% Presentation
Maximum-score evidence:
- one coherent story
- user decision first
- minimal technical jargon
- visible AI value
- polished interaction
- clear closing statement.

## North-Star Judge Question
Can a judge understand within five minutes:
**what fragmented decision exists, how Nivaran improves it, why AI is necessary, why it works cross-border, and what a policymaker can actually do with the result?**
