# Antigravity Prompt — Review a Completed Phase

Review the implementation of:

**PHASE: <phase>**

Read:
- AGENTS.md
- relevant hackathon specifications
- phase acceptance criteria
- actual changed files
- tests.

Do not implement unless a defect is found.

Audit for:
- requirement coverage
- data correctness
- fabricated/fallback behavior
- AI grounding
- deterministic score correctness
- auth/role correctness
- loading/error states
- performance regressions
- security issues
- cross-border assumptions
- tests that prove behavior rather than merely execution.

Classify findings:
P0 blocker / P1 important / P2 nice-to-have.

For each finding:
- evidence
- root cause
- affected files
- recommended fix
- verification method.

If there are no blockers, explicitly state why the phase is ready to advance.
